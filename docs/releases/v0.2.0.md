# FortiVPN GUI v0.2.0

**FortiVPN GUI** is a **Linux** desktop VPN client built with **Electron**, **React**, and **Material UI**. It drives **FortiGate** tunnels via the system **`openfortivpn`** binary and optional **Barracuda** profiles via **`barracudavpn`**. Configuration under **`~/.fortivpngui/`** uses an **INI-style layout** compatible with **OpenFortiGUI** (profile/group import and optional `main.conf` merge).

## Highlights

### New in 0.2.0

- **Internationalization (i18n)**: full UI translations for **English**, **Portuguese**, **Spanish**, **French**, **Italian**, and **German**; follows the **OS locale** automatically; override in **Settings → GUI → Language** (flag icons in the dropdown). Preference stored as **`gui/language`** in **`main.conf`** (`system`, `en`, `pt`, `es`, `fr`, `it`, or `de`).
- **Light theme** and **header theme toggle** (**dark**, **light**, **system**) with moon, sun, and computer icons; preference persisted as **`gui/theme_mode`** in **`~/.fortivpngui/main.conf`**.
- **FortiGate OTP**: **one prompt per reconnect cycle**; after an **invalid OTP**, choose **disconnect** or **request a new code** instead of being stuck in a repeated prompt loop. Removed the transient *“Validating one-time password…”* snackbar after submit.
- **`.deb` install/upgrade`**: **`postinst`** now **stops running instances** and removes **`~/.config/fortivpngui`** (Electron/Chromium cache) so the new package loads without a reboot; **VPN data in `~/.fortivpngui/` is kept**. Sudoers drop-in and **`postrm`** behaviour unchanged from 0.1.0.

### From 0.1.0 (unchanged core)

- **FortiGate** profiles: `sudo openfortivpn` with generated configs, **OTP on stdin**, gateway certificate prompts and **`trusted-cert`** handling, traffic stats, per-profile log files.
- **Barracuda** profiles: isolated temp config directories and **stdin OTP** where supported.
- **VPN groups**: connect/disconnect member profiles together with aggregated status.
- **System tray**: quick connect/disconnect, show main window, Settings, and a clean **Quit** path (stops VPN helpers and cleans packaged temp artefacts).
- **Close main window** hides to tray; **orphan** `openfortivpn` temp configs under `TMPDIR` are swept **without** stopping active tunnels.
- **Settings**: configurable paths, AES key/IV, **keytar** / libsecret integration, notifications, profile search, OpenFortiGUI import/merge.
- **External links** (`http`, `https`, `mailto`) open in the **system default browser** (navigation is guarded in the Electron main process).
- **Debian package**: `postinst` installs **`/etc/sudoers.d/fortivpngui`** from an unpacked template (`asarUnpack`); **`postrm`** removes that drop-in on **`remove`** / **`purge`** (not on **upgrade**).

## Requirements

- **Linux** with `openfortivpn`, `ppp`, and `sudo` for FortiGate; optional `barracudavpn` for Barracuda.
- **`.deb` install**: also **`libsecret-1-0`** for optional OS credential storage.

## Install

1. Download **`fortivpngui_0.2.0_amd64.deb`** from this release (or build with `npm run dist`).
2. Install, for example: `sudo apt install ./fortivpngui_0.2.0_amd64.deb`
3. Review/tighten sudoers if needed: `sudo visudo -f /etc/sudoers.d/fortivpngui`
