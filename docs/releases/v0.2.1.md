# FortiVPN GUI v0.2.1

**FortiVPN GUI** is a **Linux** desktop VPN client built with **Electron**, **React**, and **Material UI**. It drives **FortiGate** tunnels via the system **`openfortivpn`** binary and optional **Barracuda** profiles via **`barracudavpn`**. Configuration under **`~/.fortivpngui/`** uses an **INI-style layout** compatible with **OpenFortiGUI** (profile/group import and optional `main.conf` merge).

## Highlights

### New in 0.2.1

- **VPN log windows** now follow the **active UI theme** (**dark**, **light**, or **system**), matching the main window; open log windows **refresh when the theme changes** (including OS theme updates in **system** mode).
- **Changelog dialog**: fixed height with **vertical scroll** in the version list so future releases stay readable without resizing the modal; title and **OK** button remain visible.
- **Production build**: Vite bundles **React** and **Material UI** into separate chunks (smaller main bundle, cleaner build output).

### From 0.2.0

- **Internationalization (i18n)**: English, Portuguese, Spanish, French, Italian, German; **Settings → GUI → Language**; `gui/language` in `main.conf`.
- **Light theme** and header toggle (**dark** / **light** / **system**); `gui/theme_mode` in `main.conf`.
- **FortiGate OTP**: one prompt per reconnect cycle; invalid OTP offers disconnect or a new code.
- **`.deb` install/upgrade`**: postinst stops instances and clears `~/.config/fortivpngui` (Electron cache); VPN data in `~/.fortivpngui/` is kept.

See [v0.2.0 release notes](v0.2.0.md) for the full 0.2.0 feature list and core capabilities from 0.1.0.

## Requirements

- **Linux** with `openfortivpn`, `ppp`, and `sudo` for FortiGate; optional `barracudavpn` for Barracuda.
- **`.deb` install**: also **`libsecret-1-0`** for optional OS credential storage.

## Install

1. Download **`fortivpngui_0.2.1_amd64.deb`** from this release (or build with `npm run dist` after setting version to `0.2.1` in `package.json`).
2. Install, for example: `sudo apt install ./fortivpngui_0.2.1_amd64.deb`
3. Review/tighten sudoers if needed: `sudo visudo -f /etc/sudoers.d/fortivpngui`
