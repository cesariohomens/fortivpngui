# FortiVPN GUI v0.3.0

**FortiVPN GUI** is a **Linux** desktop VPN client built with **Electron**, **React**, and **Material UI**. It drives **FortiGate** tunnels via the system **`openfortivpn`** binary. Configuration under **`~/.fortivpngui/`** uses an **INI-style layout** compatible with **OpenFortiGUI** (profile/group import and optional `main.conf` merge).

## Highlights

### New in 0.3.0

- **No silent auto-reconnect.** Earlier versions always wrote `persistent = 60` into the generated `openfortivpn` config, so a dropped tunnel was retried every minute without telling the user. Reconnecting is now the **user's decision** by default.
- **Reconnect interval is configurable per profile.** The `openfortivpn` **`persistent`** option is exposed in the VPN editor (**Options → Advanced → Reconnect interval (seconds)**). Leave it **empty** or **`0`** to disable automatic reconnection; set any positive number of seconds to keep the old retry behaviour.
- **Disconnect warning dialog.** When a tunnel drops without the user asking for it, a **Warning** dialog (styled like the **About** modal) explains **why** and shows the **last log lines**. Detected reasons:
  - authentication rejected by the gateway
  - invalid or expired one-time password
  - gateway certificate could not be validated
  - gateway unreachable (DNS, routing, firewall)
  - connection timed out
  - connection reset / closed by the gateway
  - `pppd` failure
  - `sudo` refused to run `openfortivpn`
  - VPN helper binary missing
  - generic tunnel-down and unknown causes
- **User-initiated disconnects stay silent** — stopping a VPN from the UI, the tray, or on quit does not raise the warning.
- **RPM packages** are now produced alongside **`.deb`** (**Fedora**, **RHEL**, **openSUSE**), with dedicated RPM scriptlets (`%post` / `%postun` semantics), `libsecret` dependency, and `restorecon` labelling for SELinux systems.
- **Warning dialog and reconnect setting are fully translated** in all six shipped languages (English, Portuguese, Spanish, French, Italian, German).
- **Reconnect interval field** no longer shows the long openfortivpn helper paragraph under the control.

### Upgrade notes

- Existing profiles with `persistent = true` (or `persistent = 1`) in `~/.fortivpngui/vpnprofiles/*.conf` are read as **60 seconds**, so current behaviour is preserved on upgrade. Set the field to `0` in the editor to stop auto-reconnecting.
- Profiles that never had the option keep **`0`** (no auto-reconnect), which is the new default for new profiles.

### From 0.2.1

- **VPN log windows** follow the active UI theme (dark / light / system) and refresh when the theme changes.
- **Changelog dialog**: fixed height with vertical scroll for long release lists.
- **Production build**: Vite splits React and Material UI into separate chunks.

### From 0.2.0

- **Internationalization (i18n)**: English, Portuguese, Spanish, French, Italian, German; **Settings → GUI → Language**; `gui/language` in `main.conf`.
- **Light theme** and header toggle (**dark** / **light** / **system**); `gui/theme_mode` in `main.conf`.
- **FortiGate OTP**: one prompt per reconnect cycle; invalid OTP offers disconnect or a new code.
- **`.deb` install/upgrade**: postinst stops instances and clears `~/.config/fortivpngui` (Electron cache); VPN data in `~/.fortivpngui/` is kept.

See [v0.2.1](v0.2.1.md) and [v0.2.0](v0.2.0.md) release notes for the earlier feature lists and core capabilities from 0.1.0.

## Requirements

- **Linux** with `openfortivpn`, `ppp`, and `sudo`.
- **`.deb` install**: also **`libsecret-1-0`** for optional OS credential storage.
- **`.rpm` install**: also **`libsecret`** for optional OS credential storage.

## Install

### Debian / Ubuntu

```bash
sudo apt install ./fortivpngui_0.3.0_amd64.deb
```

### Fedora / RHEL

```bash
sudo dnf install ./fortivpngui-0.3.0.x86_64.rpm
```

### openSUSE

```bash
sudo zypper install ./fortivpngui-0.3.0.x86_64.rpm
```

Then review or tighten the sudoers drop-in if needed:

```bash
sudo visudo -f /etc/sudoers.d/fortivpngui
```

## Build from source

```bash
npm ci
npm run dist        # .deb + .rpm
npm run dist:deb    # .deb only
npm run dist:rpm    # .rpm only (needs rpmbuild / rpm-build installed)
```

Artifacts are written to `release/`.
