# FortiVPN GUI v0.5.2

**FortiVPN GUI** is a **Linux** desktop VPN client built with **Tauri 2** (Rust), **React**, and **Material UI**. It drives **FortiGate** tunnels via the system **`openfortivpn`** binary. Configuration under **`~/.fortivpngui/`** uses an **INI-style layout** compatible with **OpenFortiGUI**.

## Highlights

### Fixed in 0.5.2

- **Tunnel dropped right after a successful login on pppd ≥ 2.5.** Authentication (including OTP) completed, the gateway allocated an address, and then `pppd` reported `Peer refused to agree to his IP address`, followed a minute later by `Timed out waiting for the ppp interface to be UP`. The app always wrote `pppd-accept-remote` to the generated config; with the profile option **Accept remote** unchecked that meant `pppd-accept-remote = 0`, which disables openfortivpn's own version detection and is exactly the setting that breaks pppd 2.5.0 and newer. The key is now written **only when the option is enabled**, so openfortivpn's default (auto: on for pppd ≥ 2.5, off for older pppd) applies. The option's help text explains the new behaviour.

### From 0.5.1

- OTP prompt detection fix (dialog opens as soon as `openfortivpn` asks for the token), *Request new OTP* reconnects when the process has exited, Flatpak packaging.

## Requirements

- **Linux** with `openfortivpn`, `ppp`, and `sudo`.
- **Development**: Node.js **20+**, npm, **Rust** (stable), and Tauri system libs (`webkit2gtk-4.1`, `gtk3`, `librsvg`, `openssl`).
- **`.deb` install**: also **`libsecret-1-0`** for optional OS credential storage.
- **`.rpm` install**: also **`libsecret`** for optional OS credential storage.
- **Flatpak**: host `openfortivpn`, `ppp`, and `sudo` (the VPN helper runs outside the sandbox); install the sudoers drop-in on the host.

## Install

### Debian / Ubuntu

```bash
sudo apt install ./fortivpngui_0.5.2_amd64.deb
```

### Fedora / RHEL

```bash
sudo dnf install ./fortivpngui-0.5.2-1.x86_64.rpm
```

### openSUSE

```bash
sudo zypper install ./fortivpngui-0.5.2-1.x86_64.rpm
```

### AppImage

```bash
chmod +x fortivpngui_0.5.2_amd64.AppImage
./fortivpngui_0.5.2_amd64.AppImage
```

### Flatpak

```bash
flatpak install --user ./fortivpngui_0.5.2_x86_64.flatpak
flatpak run com.cesariogarcia.fortivpngui
```

Then review or tighten the sudoers drop-in if needed:

```bash
sudo visudo -f /etc/sudoers.d/fortivpngui
```

## Build from source

```bash
npm ci
npm run dist           # .deb + .rpm + AppImage + Flatpak
npm run dist:deb       # .deb only
npm run dist:rpm       # .rpm only (needs rpmbuild)
npm run dist:appimage  # AppImage only (needs appimagetool + squashfs-tools)
npm run dist:flatpak   # Flatpak only (needs an existing .deb + flatpak-builder)
```

Artifacts are written under `src-tauri/target/release/bundle/`.
