# FortiVPN GUI v0.5.0

**FortiVPN GUI** is a **Linux** desktop VPN client built with **Tauri 2** (Rust), **React**, and **Material UI**. It drives **FortiGate** tunnels via the system **`openfortivpn`** binary. Configuration under **`~/.fortivpngui/`** uses an **INI-style layout** compatible with **OpenFortiGUI** (profile/group import and optional `main.conf` merge).

## Highlights

### New in 0.5.0

- **Tauri / Rust desktop shell.** The Electron main process is replaced by a native **Tauri 2** backend written in **Rust**, with the same React / Material UI renderer.
- **Same UX and config.** Profiles, groups, settings, tray, OTP / SAML / gateway-cert flows, and OpenFortiGUI-compatible INI under `~/.fortivpngui/` behave as before.
- **Smaller runtime.** No Chromium/Electron bundle; the UI runs in the system WebKitGTK webview.
- **New tooling.** Development uses `npm run tauri:dev`; packages are built with `npm run dist` / `cargo tauri build` (`.deb`, `.rpm`, and **AppImage**).
- **Password store.** Optional OS credential storage uses the Rust **keyring** crate (libsecret) instead of Electron **keytar**.

### Upgrade notes

- **Existing VPN data is kept.** Profiles, groups, and `main.conf` under `~/.fortivpngui/` are unchanged.
- **Uninstall Electron leftovers if needed.** Old Electron user caches may still exist under `~/.config/fortivpngui`; they are unused by 0.5.0 and safe to remove manually.
- **Rebuild packages from source** with the new Tauri pipeline; artifact paths are under `src-tauri/target/release/bundle/` (or `debug/bundle/` for debug builds).
- **Sudoers** for `openfortivpn` is unchanged (`/etc/sudoers.d/fortivpngui`).

### From 0.4.0

- FortiGate-only focus, themed OverlayScrollbars, MUI copy/delete dialogs, full `openfortivpn` option coverage with version gating, reconnect interval under Options → Advanced.

See [v0.4.0](v0.4.0.md), [v0.3.0](v0.3.0.md), [v0.2.1](v0.2.1.md), and [v0.2.0](v0.2.0.md) for earlier notes.

## Requirements

- **Linux** with `openfortivpn`, `ppp`, and `sudo`.
- **Development**: Node.js **20+**, npm, **Rust** (stable), and Tauri system libs (`webkit2gtk-4.1`, `gtk3`, `librsvg`, `openssl`).
- **`.deb` install**: also **`libsecret-1-0`** for optional OS credential storage.
- **`.rpm` install**: also **`libsecret`** for optional OS credential storage.

## Install

### Debian / Ubuntu

```bash
sudo apt install ./fortivpngui_0.5.0_amd64.deb
```

### Fedora / RHEL

```bash
sudo dnf install ./fortivpngui-0.5.0.x86_64.rpm
```

### openSUSE

```bash
sudo zypper install ./fortivpngui-0.5.0.x86_64.rpm
```

Then review or tighten the sudoers drop-in if needed:

```bash
sudo visudo -f /etc/sudoers.d/fortivpngui
```

## Build from source

```bash
npm ci
npm run dist           # .deb + .rpm + AppImage via Tauri
npm run dist:deb       # .deb only
npm run dist:rpm       # .rpm only (needs rpmbuild)
npm run dist:appimage  # AppImage only (needs appimagetool + squashfs-tools)
```

Artifacts are written under `src-tauri/target/release/bundle/`.

### AppImage

```bash
chmod +x fortivpngui_0.5.0_amd64.AppImage
./fortivpngui_0.5.0_amd64.AppImage
```
